# 人物档案深度设计指南

> 把 200 字"备注"升级为有血有肉的"小传"
> 让 AI 真正"读懂"每个联系人，写出符合其人格的话术

---

## 0. 为什么需要深度档案

### 当前问题

现有 20 个联系人的 notes 字段平均 **200 字**，只有：
- 基础事实（认识时间 / 工作 / 一句关系描述）
- 1-2 个关键事件
- 简单标签

**这导致 AI 话术生成时只能输出通用模板**：
> "王五，好久没见，最近怎么样？"
> —— 这话对王五、对李四、对张总都说得通，但**没有针对性**。

### 目标

升级后的档案能让 AI 输出：
> "五哥，上次跟你说的 AI Agent 资料整理好了。融资的事我看着也替你紧张，这周末要不要出来跑一圈？边跑边聊。"
> —— 只有了解王五（融资压力 + 跑步爱好 + 五哥称呼 + 兄长的语气）才能生成。

### 核心原则

> **人物不是事实的集合，而是"特定场景下做合理反应的真人"**。

| 维度 | "事实"档案 | "真人"档案 |
|---|---|---|
| 基础信息 | 31 岁，AI 工程师 | 31 岁，父亲希望他接班做制造业，但他选了 AI，父亲至今有些失落 |
| 行为习惯 | 偶尔跑步 | 跑步是释放压力的出口，但只在焦虑超过阈值才跑 |
| 关系模式 | 老朋友 | 表面嘻嘻哈哈，但被借钱/被问意见时会沉默 5 秒 |
| 内心冲突 | （无） | 想帮朋友又怕越界 / 想承认脆弱又怕被认为软弱 |

## 1. 字段完整列表（v3.0 升级版）

### 1.1 基础信息层

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | uuid | 主键 |
| `name` / `nickname` / `petName` | string | 主名 / 常用名 / 私密称呼（如"五哥"）|
| `avatar` | object | 头像 |
| `gender` | enum | 男 / 女 / 其他 |
| `birthYear` / `ageRange` | number / enum | 出生年 / 年龄段 |
| `phone` / `wechat` / `email` | string | 联系方式 |
| `company` / `position` / `industry` | string | 工作信息 |
| `hometown` / `currentCity` | string | 地理 |
| `metAt` / `metScene` / `introducedBy` | ISO / string | 相识背景 |

### 1.2 关系属性层

| 字段 | 类型 | 说明 |
|---|---|---|
| `dunbarTier` | 1-4 | 邓巴圈层 |
| `strength` | 1-5 | 关系强度 |
| `valueTier` | enum | core / important / maintain / archive / alert |
| `familiarity` | enum | stranger / new / familiar / close |
| `trustLevel` | 1-5 | 信任度（不同于强度）|
| `emotionalTendency` | enum | dependent / independent / cooperative / competitive / avoidant |
| `tags` | string[] | 多维标签 |

### 1.3 🆕 深度属性层（让档案"活"起来的关键）

| 字段 | 类型 | 说明 |
|---|---|---|
| `archetype` | string | 原型（如"导师型" / "竞争者型" / "老大哥型"）|
| `publicPersona` | string | 公开形象（一句话）|
| `innerStruggle` | string | 内心主要矛盾 |
| `coreFear` | string | 最深的恐惧 |
| `deepDesire` | string | 最深的渴望 |
| `triggerTopics` | string[] | 容易引发情绪的话题（需谨慎处理）|
| `safeTopics` | string[] | 安全话题（可以轻松聊）|
| `verbalTics` | string[] | 口头禅 / 语言习惯 |
| `bodyLanguage` | string[] | 体态特征（如"思考时会摸下巴"）|
| `decisionPattern` | string | 决策模式（直觉型 / 分析型 / 等待型）|
| `conflictStyle` | string | 冲突处理风格（对抗 / 退让 / 妥协 / 协商）|
| `attachmentStyle` | string | 依恋类型（secure / anxious / avoidant / disorganized）|
| `moralCode` | string | 道德底线（绝不做什么）|

### 1.4 🆕 关键时刻层（叙事之源）

| 字段 | 类型 | 说明 |
|---|---|---|
| `formativeEvents` | array | 5-10 件塑造性格的关键事件（童年 / 少年 / 成年 / 近期）|
| `peakMoments` | array | 高光时刻（让他自豪的事）|
| `rockBottoms` | array | 谷底时刻（让他痛苦的事）|
| `unresolvedIssues` | array | 未解决问题（压在他心里的）|

### 1.5 🆕 行为模式层（场景化反应）

| 字段 | 类型 | 说明 |
|---|---|---|
| `comfortableScenarios` | array | 他自在的场景（触发后他会打开心扉）|
| `uncomfortableScenarios` | array | 他不自在的场景（触发后他会退缩）|
| `smallHabits` | array | 小习惯（点咖啡永远去冰 / 开会先看手机）|
| `giftPreferences` | object | 礼物喜好（实用型 / 体验型 / 惊喜型）|
| `conflictTriggers` | array | 容易触发冲突的话题 |

### 1.6 🆕 AI 提示词层（专为 LLM 设计）

| 字段 | 类型 | 说明 |
|---|---|---|
| `aiPersona` | string | AI 在描述这个人时该用的角色 |
| `voiceTone` | string | 对话语气（温暖 / 严肃 / 轻松 / 调侃）|
| `doNotMention` | string[] | 绝对不要提的话题（硬性底线）|
| `openWith` | string | 最适合的开场白主题（如"跑步" / "AI 项目"）|
| `suggestionRisks` | string[] | 给他建议时的风险点 |

## 4. AI 提示词使用建议

### 4.1 在 prompt 中引用档案

```javascript
const systemPrompt = `
你是一位社交助手。基于以下联系人档案，生成符合其人格的开场白：

档案：
${JSON.stringify(contact, null, 2)}

要求：
1. **开场白主题**：仅使用 safeTopics 列表中的话题
2. **避免触发**：绝对不要提 triggerTopics
3. **语气匹配**：根据 voiceTone 调整
4. **场景适配**：基于 comfortableScenarios 选择切入
5. **深度匹配**：根据 familiarity 决定深度

输出格式（JSON）：
{
  "opening_conservative": "...",
  "opening_standard": "...",
  "opening_direct": "...",
  "expectedReaction": "...",
  "risks": ["..."]
}
`
```

### 4.2 反馈学习字段

每次生成后，记录用户采纳 / 修改 / 忽略。建立一个：

```javascript
contact.aiFeedback = {

  preferredPattern: 'cautious'  // cautious / standard / direct
}
```

## 5. 5 类设计原则（让人物"活"起来）

### 5.1 矛盾原则
每个人物必须有 **1 个核心矛盾**（innerStruggle）。没有矛盾的人是纸片人。

### 5.2 行为 ≠ 内心原则
言行之间有 gap。例如：
- 表面"乐观" → 内心"怕被看低"
- 表面"随便都行" → 内心"有强烈偏好但不愿表达"

### 5.3 触发词原则
每个人都有 **2-3 个触发词**，听到立即情绪波动。在 AI prompt 中硬性规避。

### 5.4 决策模式原则
不要所有人都是"理性分析"。人群中：
- 30% 直觉型（想到就做）
- 40% 分析型（看数据再做）
- 20% 等待型（让别人先动）
- 10% 跟风型（随大流）

### 5.5 童年印记原则
每个人都有 1-2 件 **童年关键事件**，塑造了现在的性格模式。AI 不知道这些，但档案中存在，影响生成的"深度感"。

## 6. 批量生成指南

当你需要为新联系人创建深度档案：

1. **5 分钟内能写完吗？** → 太浅，需要更多挖掘
2. **档案 > 1500 字才算合格** → 否则 AI 难以理解
3. **每个字段都要具体到场景** → 避免"他很内向"
4. **档案中要有至少 1 个"我不能说出来"的点** → 才是有深度的人
