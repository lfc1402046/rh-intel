### 3.5 FAQ（5-8 个）

| Q | A |
|---|---|
| 数据存在哪？ | 浏览器本地（localStorage），清除浏览器数据 = 清除应用数据 |
| 能多端同步吗？ | MVP 暂不支持，v1.5+ 加。MVP 阶段可用"导出 JSON"手动备份 |
| 怎么备份？ | 工具内"导出 JSON"按钮，一键备份全部数据 |
| 浏览器不兼容？ | 推荐 Chrome 90+ / Edge 90+ / Firefox 88+ / Safari 14+ |
| AI 增强怎么用？ | 工具设置里填入你的 LLM API key（OpenAI/Claude/DeepSeek 等） |
| AI key 存在哪？ | 浏览器本地，不上传任何服务器 |
| 完全免费吗？ | MVP 阶段完全免费。v1.5+ 将引入付费层（基础功能永久免费） |
| 如何反馈？ | 页面底部"联系"或 GitHub Issues |
