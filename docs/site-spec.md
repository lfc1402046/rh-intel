## 5. 接口契约（v1.5+ BFF 预留）

> MVP 阶段不实现，但规划清楚，方便后续对接

| 方法 | 端点 | 用途 | 鉴权 |
|---|---|---|---|
| POST | `/api/auth/register` | 用户注册 | 公开 |
| POST | `/api/auth/login` | 用户登录 | 公开 |
| GET | `/api/auth/me` | 当前用户信息 | Bearer Token |
| POST | `/api/payment/wxpay` | 微信支付下单 | Bearer |
| POST | `/api/payment/callback` | 微信回调 | 签名验证 |
| GET | `/api/subscription/me` | 订阅状态 | Bearer |
| POST | `/api/sync/upload` | 数据上传 | Bearer |
| GET | `/api/sync/download` | 数据下载 | Bearer |
| GET | `/api/usage/ai-quota` | AI 配额查询 | Bearer |

**统一响应格式**：
```json
{ "code": 0, "data": {}, "msg": "ok" }
```

**统一错误码**：
- 0 成功
- 401 未授权
- 403 禁止
- 404 不存在
- 500 服务错误

## 6. 转化路径

### 6.1 主要路径
```
落地页访问 → 浏览首页 → 点击"立即下载" → 下载 HTML → 打开工具 → 注册
                                  ↓
                            浏览功能页 → 信任建立 → 再次 CTA
                                  ↓
                            提交联系表单 → 邮件通知
```

### 6.2 辅助路径
- GitHub 角标 → 看源代码 → 评估后下载
- 演示视频 → 直观了解 → 下载
- 隐私页 → 信任建立 → 下载

### 6.3 关键指标追踪
- 落地页 UV / PV
- 6 模块卡片的点击率
- "立即下载"按钮的点击率
- 联系表单提交数
- GitHub 仓库 stars
