隐私政策

你的关系
永远属于你

最后更新：2026 年 10 月 9 日

1. 数据存储

所有联系人数据存储在你的浏览器本地（localStorage）。我们的服务器不接收你的联系人数据。清除浏览器数据 = 清除应用数据。

2. 第三方服务

联系表单：Formspree.io（仅你提交时发送，不存储联系人内容）

AI 增强：使用你自带的 API key，直接调用 LLM（OpenAI/Claude/DeepSeek 等）。我们不代理你的调用。

访问分析：可选 Google Analytics 或百度统计（仅匿名访问数据）。

3. 我们不收集

  • 你的联系人列表
  • 你的互动记录
  • 你的备注内容
  • 你的标签
  • 你的关系图谱数据

4. 你的权利

  • 随时导出全部数据（JSON 格式）
  • 随时删除全部数据
  • 工具本体开源，可审查代码
  • 无锁定，可自由迁移

5. Cookie

RH Intel 本身不使用 cookie。如启用 Google Analytics，会使用必要的 cookie 用于匿名访问统计。

6. 政策变更

如有重大变更，我们会在 GitHub Releases 中发布说明。

7. 联系

如有隐私相关问题，请通过 联系页 或 GitHub Issues 反馈。
