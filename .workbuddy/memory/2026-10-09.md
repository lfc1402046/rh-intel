**核心交付**：

1. **产品定位转变**：
   - 从"工具"（用户主动使用）→ "AI 助手"（AI 主动推送）
   - 触发从"用户打开应用"→ "定时 + 事件触发"
   - 关键洞察：用户最大痛点不是"工具不好用"，而是"懒得用"

2. **4 类主动推送场景**：
   - 冷淡关系提醒（强度高 + 长期无互动）
   - 重要日期提醒（生日 / 纪念日）
   - 待办到期提醒
   - AI 洞察（关系异常分析）

3. **3 大自动化能力**：
   - 定时扫描：每日 9:00（可配）
   - 智能分析：5 类 LLM 任务（冷淡分析 / 话术 / 生日 / 周报 / 月报）
   - 多通道推送：Web Push（主）+ 邮件 + 微信公众号

4. **关系衰减算法**（decayScore）：
   - 0-0.5x 间隔：fresh
   - 0.5-1x：normal
   - 1-2x：warm
   - 2-3x：cold
   - 3x+：frozen

5. **BFF API 设计**（8 个端点）：
   - /api/scan/trigger、/api/scan/schedule
   - /api/alerts、/api/alerts/:id
   - /api/push/subscribe、/api/push/unsubscribe
   - /api/settings/notifications

6. **3 个数据结构**：
   - 扫描结果（含 4 类 results）
   - 提醒（含 4 种 actions）
   - 用户配置（含推送偏好 + AI key + 静默时段）

7. **UI 增强**：
   - 新页面 /alerts（提醒中心）
   - 新页面 /ai-settings（AI 配置）
   - Header 通知铃铛
   - 看板"今日 AI 建议"卡片
   - Service Worker（Web Push 核心）

8. **5 阶段实施路线**：
   - 阶段 1（MVP，1-2 周）：Web Push + 扫描 + 3 类基础提醒
   - 阶段 2（3-5 天）：邮件 + 智能聚合
   - 阶段 3（1-2 周）：微信公众号
   - 阶段 4（2-4 周）：AI 深度增强
   - 阶段 5（4+ 周）：智能体化对话

9. **6 类风险与缓解**：
   - 推送骚扰 → 智能聚合 + 静默 + 频率 ≤ 5/天
   - 数据隐私 → 用户自带 key + 端到端加密
   - AI 误判 → 置信度显示 + 用户反馈学习
   - 成本失控 → 客户端调用 + ≤ 3 次 AI/天
   - 定时任务失败 → 多区域冗余 + 健康检查
   - 公众号资质 → 推迟到阶段 3，先做 Web Push
