## 🚀 使用方法

### 在 RH Intel 工具中导入

1. 打开工具（`tool/index.html`）
2. 找到工具内"导入 JSON"按钮（或"设置 → 数据管理"）
3. 选择 `tool/sample-data.json`
4. 工具自动加载 20 个联系人 + 互动记录 + 待办 + 关键日期

### 测试清单

打开工具后，逐项验证：

- [ ] 联系人列表显示 20 人
- [ ] 图谱视图显示网络结构（含 6 对预设连接）
- [ ] 看板显示至少 4 条"今日 AI 建议"
- [ ] 时间线显示 20 条互动记录
- [ ] 关键日期倒计时正确
- [ ] 待办列表显示 10+ 项
- [ ] 标签筛选器可用
- [ ] 圈层筛选器可用

### 作为新功能测试数据

新增任何功能时，可以用此数据集：
- **新筛选规则**：测试 4 圈层 × 6 标签的各种组合
- **AI 话术生成**：测试对王五、小敏、爸的不同语气
- **冷淡提醒**：验证"超 30 天"阈值是否准确触发
- **关系洞察**：跑图算法看是否能识别"周教练是枢纽"

## 🔧 数据扩展

如需添加更多联系人：

```json
{
  "id": "c021",
  "name": "...",
  "tags": ["..."],
  "connections": [{ "targetId": "c001", "type": "..." }],
  ...其他字段参考现有联系人
}
```

在 `tool/sample-data.json` 的 contacts 数组末尾添加即可。

## 📝 设计原则

1. **真实感**：基于真实场景（厦门/AI/期权/跑团/糖尿病），不是抽象 ID
2. **覆盖度**：每个圈层、每种标签、每种互动方式都有
3. **测试价值**：包含"应该被识别为冷淡"的极值数据
4. **隐私**：所有姓名是虚构的，关系是抽象的
5. **可读性**：备注含自然语言，适合 AI 测试 prompt 模板
